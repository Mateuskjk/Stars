Como conectar

  1. Gere seu token em Configurações › Membros (botão “Gerar token”).
  2. Envie o token no cabeçalho de toda requisição: Authorization: Bearer stars_…
  3. Use a URL base abaixo. Respostas em JSON, até 60 requisições por minuto por token.

{{ baseUrl() }}

O token respeita as permissões do dono (ex.: sem acesso a Projetos → HTTP 403 em /projects). Cada chamada fica registrada em Auditorias.
